# Interview Simulator — SAP Project (Gen AI)



## What it does
- 4 role tracks (e.g. Software, Data, Marketing, HR) with 3 difficulty levels
- 5 interview questions per role
- Answer timer, instant structured feedback, and final performance summary
- Runs fully in the browser — no Python, no API key, no setup

## How to run
Just open `index.html` in any browser, pick a role and difficulty, and start the interview.

## How to use for SIP report
1. Open `index.html`
2. Run a full mock interview
3. Take screenshots of: home/role select, question screen, answer + feedback, final summary
4. Paste them into your report as working-app proof

## Tech
HTML, CSS, JavaScript (single file, offline-friendly)
